# phalanx (PPDB parts)

Phalanx is shared by all of Rubin's Kubernetes services. Only these apps are
PPDB's:

| App | Runs in | What |
|---|---|---|
| `applications/ppdb-replication` | `usdfdev`, `usdfint`, `usdfprod` | Two deployments from the `ghcr.io/lsst/ppdb-replication` image (built from dax_ppdb): `exporter-deployment.yaml` runs `ppdb-replication run`, `uploader-deployment.yaml` runs `ppdb-replication upload-chunks` |
| `applications/ppdbtap` | `idfdev`, `idfint` | CADC TAP service on the BigQuery backend (`cadc-tap.config.backend: bigquery`) |

Related, not PPDB-owned: `applications/bigquery-kafka` (runs ppdbtap's BigQuery
queries) and the `sasquatch` subchart `charts/ppdbtap` (its Kafka topics).

Apps are enabled per environment in `environments/values-<env>.yaml`.

## Conventions

- Use the **`phalanx_env`** conda env here, not `ppdb_env`
  (`conda run -n phalanx_env ...`).
- Each app's `README.md` and `docs/applications/<app>/values.md` are
  **generated by helm-docs** from `# --` comments in `values.yaml`. Edit the
  comments, then run `pre-commit run --all-files` (or the helm-docs hook);
  don't hand-edit the generated files.
- Per-environment overrides go in `applications/<app>/values-<env>.yaml`.
- Secrets come from Vault (`secrets.yaml`, `vault-secrets.yaml` template).
- Upstream is lsst-sqre/phalanx, which has its own review process.
  Expect SQuaRE review on PRs.
- Changes deploy through Argo CD, never directly from here.

Full reference: `docs/components/phalanx.md`. Read it before non-trivial changes here.
